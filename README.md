Descripción del proyecto

Esta aplicación fue desarrollada utilizando Expo, React Native y TypeScript. Su función principal es mostrar un saludo personalizado y una tarjeta que cambia su contenido según su estado de carga.

Funcionalidades

* Muestra un saludo con el nombre y apellido del estudiante.
* Utiliza un componente llamado MainCard.
* Muestra el mensaje “Cargando…” cuando el estado es verdadero.
* Muestra “Contenido Listo!” cuando el estado es falso.
* Incluye un botón para cambiar entre ambos estados.
* Utiliza useState para controlar el estado de la aplicación.

Tecnologías utilizadas

* React Native
* Expo
* TypeScript
* Git
* GitHub

Cómo ejecutar el proyecto

1. Descargar o clonar el repositorio.
2. Abrir la carpeta del proyecto en Visual Studio Code.
3. Instalar las dependencias con pnpm install.
4. Ejecutar pnpm exec expo start.
